# Cave9 PWA

Play and install: https://elheron.github.io/cave9-pwa/

Open the link in Chrome on Android and choose Install app / Add to Home screen.
On iPhone, open it in Safari, choose Share → Add to Home Screen, and enable
Open as Web App if offered. Turn the phone sideways to play.

Load the game once online before starting it offline. For an update, close all
Cave9 tabs and app windows, then reopen the game.

The production game uses Three.js. The game, retained original notices and
