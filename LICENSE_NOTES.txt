# License & Credits

## This project

**Cave9** is a browser/mobile cave-runner inspired by the original `cave9` from
9Hells. The current game identity, cave visuals, formation materials and menu
textures are maintained as this project's own direction.

This repository remains licensed under **GPL-3.0-or-later** because it retains
GPL code lineage, original audio and preserved reference material. Calling the
current project "inspired by cave9" describes its identity and presentation; it
does not remove the original authors' notices from retained material.

### What was reused

* **Algorithms** ported to JavaScript from the original C (`src/game.c`,
  `src/detrand.c`, `src/render.c`, `src/game.h`): cave digger generation,
  4-point polygon collision, thrust/gravity physics, deterministic RNG, camera
  and screen-shake behaviour. See [`src/core/`](src/core/) — each file names the
  original function it ports.
* **Retained assets** (in `public/assets/`, originals from `_original/data/`):
  * `thrust.wav`, `hit.wav`, `crash.wav` — original sound effects
  * `icon.png` — game icon
  * `hud.ttf` — original HUD font (bundled; UI currently uses system monospace)

### Derived assets

* `public/assets/cave-wall-detail.webp` and
  `public/assets/landmark-rock-grain.webp` — original project assets generated
  with OpenAI's built-in ImageGen workflow on 2026-08-08, then downscaled and
  encoded locally. No third-party bitmap was supplied as an image input. The
  former is the direct 512 px near-field cave colour-detail map; the latter is
  the direct 256 px wet-rock landmark grain. Both are distributed under this
  project's GPL-3.0-or-later license.

* `public/assets/cave-wall-height.png` and
  `public/assets/cave-wall-normal.png` — deterministic, lossless derivatives of
  `cave-wall-detail.webp`, generated by `scripts/make-cave-maps.mjs`. The height
  map stores centred multi-scale detail relief; the normal map stores OpenGL
  tangent-space normals derived from that exact height field with mirrored edge
  sampling. They are loaded by the current hardware relief path while Rock
  Detail is enabled; the software-renderer fallback omits them. They share the
  source asset's GPL-3.0-or-later license.

* `docs/assets/coiling-rock-detail.webp` — original project asset generated
  with OpenAI's built-in ImageGen workflow on 2026-08-08, using the neutral cave
  texture as a tone reference and a real Coiling capture only as a directional
  form reference. It is a high-key, diagonally striated material modulation map;
  it contains no copied scene geometry. `coiling-rock-height.png` and
  `coiling-rock-normal.png` are deterministic lossless derivatives generated by
  `scripts/make-coiling-maps.mjs`. The detail source is retained outside the
  production bundle; its generated normal/height maps under `public/assets/`
  are used by the current hardware Coiling relief path.
  They are distributed under this project's GPL-3.0-or-later license.

* `public/assets/icon.svg` — original project vector artwork added on
  2026-09-29. `icon-192.png` and `icon-512.png` are browser-rasterized derivatives
  of that SVG, distributed under the project's GPL-3.0-or-later license.
  The retained original `icon.png` remains the 64-pixel fallback.

* `src/ui/textures/` — original project UI materials generated with OpenAI's
  built-in ImageGen workflow on 2026-08-09 from the project's V2/V3/V4 visual
  direction. The active `v2/` pack contains fifteen transparent panel, button,
  slider, divider and semantic-state components; the slider rail, hinge and
  lever are independent layers. The earlier three 256×256 materials are kept as
  historical sources. None contains text, logos or third-party bitmap inputs;
  all are distributed under this project's GPL-3.0-or-later license.

* The former `public/assets/wall-normal.png` was a historical tangent-space
  **normal map**
  mechanically derived from `wall.jpg` during Phase 4D/L2 (luminance → blur →
  Sobel → tangent-space normal). As a derivative of the GPLv3 `wall.jpg` it is
  **GPL-3.0-or-later**, same as this project, and contained no external data. The
  former `scripts/make-normalmap.mjs` generator and package command were retired
  when the active cave surface moved to fixed-cost facet shading plus one
  distance-bounded generated colour-detail sample in
  [`caveFacet.js`](src/render/materials/caveFacet.js) and
  [`Renderer.js`](src/render/Renderer.js). The retained asset is historical and
  was removed from the shipped assets and is not part of the current cave
  render path.
